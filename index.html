Sobre el proyecto

Este proyecto fue desarrollado utilizando HTML5, CSS3 y el framework Bootstrap para crear una interfaz moderna, funcional y adaptable a diferentes tamaños de pantalla.

Objetivos

  • Utilizar HTML5 y CSS.
  • Integrar Bootstrap.
  • Aplicar selectores CSS.
  • Utilizar el modelo de caja.
  • Crear un diseño responsivo.

Características

HTML5

Estructura semántica y organizada para la página.

CSS3

Estilos personalizados utilizando diferentes selectores y propiedades.

Bootstrap

Componentes y clases para crear un diseño responsivo.
